# Dashboard

---

## Overview

The dashboard is the first page users see after completing the login and OTP verification process.  
It provides a quick overview of the system and shortcuts to the core modules.

The content shown depends on the user’s role.

---

## Features

### **Quick Navigation**
The dashboard includes direct links to:
- Buildings  
- Logs  
- Users (Admin only)  

These shortcuts help employees access key workflows immediately.

---

### **System Summary**
The dashboard may include:
- Total number of buildings in the system  
- Count of abandoned buildings  
- Recent updates or actions  
- Pending inspections (optional based on data)  

This gives users a quick understanding of recent activity.

---

### **Role-Based Display**
Depending on the user role, the dashboard adapts:

- **Viewer**  
  - Basic system info  
  - Link to Buildings page  

- **Editor**  
  - Same as Viewer  
  - Additional shortcut to create new buildings  

- **Admin**  
  - All features from other roles  
  - Access to Users page  
  - Access to Logs  
  - High-level overview of activity  

---

## Navigation Structure

Common elements available from the dashboard:

- **Top Navigation Bar**  
  Shows user email, logout button, and module links.

- **Side or Card-Based Layout**  
  Simplifies accessing the core features.

- **Consistent Buttons**  
  e.g. “View Buildings”, “View Logs”, “Manage Users”

---

## Dashboard Goals

The dashboard is designed to:
- Give fast entry to essential system modules  
- Reduce the number of clicks to reach important pages  
- Provide clarity for municipal employees  
- Help Admins understand recent system activity  

---

## Conclusion

The dashboard serves as a simple and clear starting point for all users.  
With quick links and role-based visibility, employees can reach the information they need with minimal effort.
