# Stage B Submission Artifacts

This folder contains the Stage B submission and grading-support artifacts.

## Folder Index
- `poster/`: final poster PowerPoint, official poster template, and organized poster assets.
- `presentation/`: Beamer presentation source and rendered PDF.
- `uml/class/`: UML 2.5.1 class diagram source, PNG render, and vector PDF render.
- `uml/deployment/`: UML 2.5.1 deployment diagram source, PNG render, and vector PDF render.
- `uml/use-cases/poster/`: poster use-case diagram in UML 2.5.1 form.
- `uml/use-cases/presentation/`: presentation traceability diagram connecting use cases to issues and sprint branches.
- `customer-satisfaction/`: customer questionnaire PDF and the script used to generate it.

## Main Deliverables
- Poster: `poster/GhostHouses_Poster.pptx`
- Presentation: `presentation/StageB_Presentation.pdf`
- Customer questionnaire: `customer-satisfaction/GhostHouses_Customer_Questionnaire.pdf`
