# Documentation Index

This folder is organized by purpose so project handoff, course submission files, and technical documentation stay separate.

## Main Files
- `CONVENTIONS.md`: team workflow, issue rules, branch rules, and documentation standards.

## Folders
- `technical/`: current system documentation, setup notes, backend/frontend behavior, roles, logs, authentication, and feature explanations.
- `data-and-templates/`: Excel samples, seed/reference data files, import/export templates, and the building-card PPTX template.
- `hld/`: original HLD documents and related HLD source material.
- `notes/`: meeting notes, client notes, and temporary review material that should not be mixed with final submissions.
- `submissions/stage-a/`: Stage A rehearsal material, submitted Stage A document/PDF, examiner spreadsheet, draft files, and UML diagrams.
