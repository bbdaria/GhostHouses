# Installation & Setup

---

## Prerequisites

- **Node.js**  
  Download from https://nodejs.org.  
  After installing, run `npm` in the terminal to verify it works.

- **.env.local file**  
  Contains sensitive API keys.  
  Do not upload it to GitHub.  
  Get this file from another team member.

---

## Setup

1. Clone the repository:  
   `git clone https://github.com/YourTeam/GhostHouses.git`

2. Navigate to the project folder and install dependencies:  
   `npm install`

3. Place the `.env.local` file in the root directory (next to `package.json`).

4. Start the backend and frontend services using your preferred environment (Docker or local run).

5. Run the development server:  
   `npm run dev`  
   The website will be available at **http://localhost:3000/**.  
   Any code changes will reflect automatically.
